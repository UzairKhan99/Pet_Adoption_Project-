# Pet Adoption Project

Pet Adoption Project is a web application made for managing pet adoption online.  
The main goal of this project is to make the adoption process easier by allowing users to view available pets and send adoption requests through the system.

## About the Project

Many pet adoption systems are still handled manually, which can make it difficult to manage pet records, adoption requests, and user details properly.  
This project provides a simple platform where pets can be listed, users can browse them, and adoption requests can be managed in a more organized way.

The project has a frontend and backend structure, with Django used for the main backend logic.

## Features

- View available pets
- Add and manage pet details
- User registration and login
- Send adoption requests
- Admin-side management
- Backend database handling
- Organized frontend and backend folders
- Simple and clean user interface

## Tech Stack

- Django
- Python
- JavaScript
- HTML
- CSS

- Bootstrap
